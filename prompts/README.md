# Prompts (onboarding)

Этот каталог содержит **скрытые didactic-промпты** и **level-specific промпты**, которые runtime подмешивает в LLM instruction при прохождении уровней.

Все промпты здесь пишутся как **Nunjucks templates** (`.njk`), чтобы можно было:
- выносить повторяющиеся блоки в `partials/`;
- переиспользовать общий layout через `extends`/`block`;
- (в будущем) подключать контекстные переменные (user/task/level) без склейки строк в коде.

## Структура

- `default.njk` — didactic default prompt (общие правила/ограничения).
- `levels/<levelId>/start.njk` — hidden инициирующий prompt уровня (обязателен для уровня).
- `levels/<levelId>/iterate.njk` — hidden prompt итераций уровня (опционален; если отсутствует/не рендерится — считается пустым).
- `levels/<levelId>/check.njk` — hidden prompt проверки уровня (опционален; если отсутствует/не рендерится — считается пустым).
- `base.njk` — минимальный layout для всех шаблонов в этом каталоге.
- `partials/**` — переиспользуемые блоки (общие секции, запреты, списки, правила).

## Как писать шаблоны

Рекомендуемый формат для всех `.njk`:

- начинать с layout:
  - `{%- extends "base.njk" -%}`
  - `{%- block body -%}...{%- endblock -%}`
- повторяющиеся куски подключать через:
  - `{% include "partials/<name>.njk" %}`

### Важное про пробелы и переводы строк

Runtime использует результат рендера как plain text/markdown. Поэтому важно:
- **не добавлять ведущий перевод строки** в начале промпта;
- сохранять осознанные пустые строки внутри текста (например, между абзацами).

Для этого в большинстве шаблонов используется “whitespace control” в Nunjucks: `{%- ... -%}`.

## Как проверить изменения

- Unit: `npm run test:unit`
- Traceability: `npm run test:traceability`

Минимальная sanity-проверка для шаблонов: убедиться, что `.njk` рендерятся без ошибок и без ведущего `\n`.
