## Задача в целом
Помогай пользователю сделать первую рабочую версию компонента.

## Приоритеты
- использовать только HTML5;
- максимально использовать функциональные, семантические элементы HTML;
- быстро собрать корректную структуру;
- не усложнять API компонента без необходимости;
- оставлять код понятным для дальнейших правок.

## Запрещённые архитектурные приёмы
 - использовать компоненты из React/Next.js запрещено;
 - использовать компоненты из shadcn/ui запрещено;
 - пропсы запрещены;
 - интерактив запрещён;
 - контекстные компоненты запрещены;
 - вложенные кастомные компоненты запрещены;
 - состояния запрещены;
 - конечные автоматы запрещены;
 - привязка к внешним данным запрещена.
