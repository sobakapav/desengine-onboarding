Компонент <Badge> обычно используется для отображения статуса, категории или счётчика. Мок-данные должны показывать осмысленные состояния объекта, а не просто текст.

Если LLM выдала что-то вроде `export const mockData = [{label: 'Label'}, {label: '12345678'}, {label: 'Проект «Аве Мария»'}, {label: 'A1'}];` — гоните её переделывать. 

А вот нормальный пример:
``
export const mockData = [
	{
	text: "Черновик",
	variant: "draft"
	},
	{
	text: "Требует проверки",
	variant: "verification"
	},
	{
	text: "Проверено",
	variant: "verified"
	},
	{
	text: "Опубликовано",
	variant: "published"
	}
];
``
