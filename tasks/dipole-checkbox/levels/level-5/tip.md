Хороший `mock.ts` отвечает на вопрос «Если бы этот компонент использовался в настоящем продукте, какие данные в него передавались бы?»

У чекбокса, к примеру, был какой-то текст. «Я с чем-то согласен» или «Я что-то выбираю», но совершенно точно не 'Label':) 

А еще у самого чекбокса есть разные состояния: выбран, не выбран, заблокирован. И это было бы неплохо учесть в мок-данных.

Поэтому `mock.ts` может выглядеть как-то так:
``
export const mockData = [
	{
	label: 'Даю разрешение на обработку персональных данных',
	checked: true,
	},
	{
	label: "Получать уведомления на email",
	checked: false,
	},
	{
	label: 'Режим разработчика',
	checked: false,
	disabled: true,
	}
];
``
