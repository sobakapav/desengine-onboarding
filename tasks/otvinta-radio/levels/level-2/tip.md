На картинке, очевидно, [radiobutton](https://www.w3schools.com/tags/att_input_type_radio.asp).

Убедите LLM собрать его, используя соответствующий компонент из выбранной UI-библиотеки:
1. [Компонент `<Radio Group>`](https://ui.shadcn.com/docs/components/radix/radio-group) из библиотеки [ui.shadcn](https://ui.shadcn.com/).
2. [Компонент `<Radio>`](https://ant.design/components/radio) из [Ant Design](https://ant.design/).
3. [Компонент `<Radio Group>`](https://mui.com/material-ui/react-radio-button/) из [Material UI](https://mui.com/material-ui/).
